# 🌡️ Conversor de Celsius para Kelvin

Programa simples de conversão de temperatura desenvolvido em Python, que transforma valores de Celsius para Kelvin.

O programa permite que o usuário informe uma temperatura, visualize o resultado da conversão e realize várias conversões sem precisar reiniciar a aplicação.

---

## 🚀 Tecnologias

- Python 3

---

## ⚙️ Funcionalidades

✔ Converte temperaturas de Celsius para Kelvin  
✔ Aceita números inteiros e decimais  
✔ Exibe o resultado da conversão no terminal  
✔ Permite realizar várias conversões na mesma execução  

---

Este projeto foi desenvolvido para praticar conceitos básicos de programação em Python, incluindo variáveis, entrada de dados, operações matemáticas e estruturas de repetição.
